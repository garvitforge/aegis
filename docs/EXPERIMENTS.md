# Experiments

This document will record measurable experiments rather than subjective claims.

## Planned benchmark

Compare path-planning strategies on identical maps using:

- Path length
- Planning time
- Nodes expanded
- Failure rate
- Replanning time after an obstacle changes

## Reproducibility

Every benchmark should record:
- Map dimensions
- Obstacle layout or random seed
- Start and goal
- Algorithm
- Python version
- Hardware, when relevant
